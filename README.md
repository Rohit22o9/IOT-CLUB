# JSPM's JSCOE IoT Club Website

An ultra-premium, interactive website for **JSPM's JSCOE IoT Club** featuring an 800-frame scroll-driven canvas walkthrough into the IoT Laboratory, showcases of student achievements, project milestones, and club coordinators.

## 🚀 Features

- **Cinematic Canvas Engine**: 800-frame scroll-synchronized animation taking visitors from the doorway entrance down the corridor and into the IoT Lab.
- **Section Choreography**:
  - **Screen 1**: Hero Entrance & Vision with interactive CTA buttons.
  - **Screen 2**: "Building Ideas for a Smarter Tomorrow" featuring live metrics, pillars, and 4 domain showcase cards.
  - **Screen 3**: Achievements Showcase featuring a 3D rotating cylinder carousel, video showcase, and competition awards.
  - **Screen 4**: "Meet Our Members" student year cards, coordinators profiles, and contact hub.
- **High Performance**: Vanilla HTML5, CSS3, Canvas API, and Node.js with high-DPI retina support and zero external framework overhead.

## 🛠️ Getting Started

```bash
# Clone the repository
git clone https://github.com/Rohit22o9/IOT-CLUB.git

# Enter project directory
cd IOT-CLUB

# Start local server
node server.js
```

Open `http://localhost:3000/` in your browser.
